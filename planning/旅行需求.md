## 三、三个可行方案（按推荐度排序）

### 🥇 方案 B：开口程「深圳→维也纳 / 布达佩斯→广州」← 推荐

- **去程** 1/23（六）深圳 SZX → 维也纳 VIE，海航 HU789 直飞 **¥3,357**
- **返程** 2/2（二）布达佩斯 BUD → 广州 CAN，南航 CZ650 直飞 **¥3,313**
- **机票合计 ¥6,670**，无额外地面折返成本
- 动线：**维也纳 →（湖区）→ 布拉格 → 布达佩斯 → 飞走**，完全不回头
- 两条腿都是各自方向上的低价腿

### 🥈 方案 A：南航往返「广州 ⇄ 布达佩斯」

- 1/23 去 / 2/2 回，往返直飞 **¥5,626**（一张票，最便宜、最稳）
- 动线：布达佩斯 → 布拉格 → 维也纳(+湖区) → **折返布达佩斯 2.5h 火车**
- 额外地面成本：维也纳→布达佩斯火车 ¥150–320 + 布达佩斯 1 晚 ¥400–800 ≈ **¥550–1,120**
- **总到手成本 ≈ ¥6,176–6,746** —— 与方案 B 基本打平，但要折返

### 🥉 方案 C：开口程「广州→布达佩斯 / 维也纳→深圳」

- CAN→BUD 1/23 ¥3,287 + VIE→SZX 2/3 ¥4,074 = **¥7,361**
- 最贵：回程 VIE→SZX 撞春运高峰（¥4,074）

### 结论

方案 A 与 B **到手成本几乎相同（差 ¥0–500）**，但 B 完全不折返、省半天和一晚折腾 → **推荐 B**。
若极度看重"一张票、最稳、最省"，选 A。

## 九、工具

| 文件 | 作用 |
|---|---|
| `scripts/track_price.py` | 每周抓价，写 `data/prices.csv` + `site/data.json` |
| `scripts/scan.py` | 临时比价，扫描任意「航线+日期」，不写历史 |

| `scripts/build_site.py` | 渲染整站 → Git 仓库（含压缩图片） |
| `scripts/version.py` | 生成版本号 + 时间戳 |
| `scripts/config.json` | 要追踪的航段配置 |
| `data/prices.csv` | 价格历史 |
| `snapshots/` | 抓价时的页面截图 |

```bash
python scripts/track_price.py               # 抓一次价
python scripts/track_price.py --show        # 看历史
python scripts/scan.py CAN BUD 2027-01-26   # 临时查某一天
python scripts/fetch_photos.py              # 补抓缺失的图
python scripts/build_site.py                # 重建整站
python scripts/version.py "改动说明"         # 打版本号（提交前跑）
```
