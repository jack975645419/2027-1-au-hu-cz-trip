## 一、签证（申根）— 最重要，最早启动

**递哪个国家？** 按"停留最长国"原则。以方案 B 的住宿分配算：

| 国家 | 晚数 | |
|---|---|---|
| **奥地利**（维也纳 3 + 湖区 1） | **4** | ✅ 最长，且是首入国 |
| 捷克（布拉格 3） | 3 | |
| 匈牙利（布达佩斯 3） | 3 | |

→ **向奥地利递交**。行程天数若改了，重新算一遍；并列时以首入国为准。

**时间节奏**
- 最早可提前 6 个月递交，最晚建议出行前 **15 个工作日**以上
- **建议 2026 年 10 月底 – 11 月初递交**（出发前约 3 个月），避开圣诞积压
- 首次申根需**本人现场录指纹**（59 个月内有效）

**材料清单**
- [ ] 护照：有效期 ≥ 离境后 3 个月，至少 2 页空白
- [ ] 签证申请表（在线填 + 打印签名）
- [ ] 近 6 个月白底证件照（35×45mm）
- [ ] **行程单**（英文，日期/城市/交通/住宿，要和实际一致）
- [ ] **酒店预订单**（Booking 可免费取消的即可，要覆盖全部夜晚）
- [ ] **机票预订单**（往返/开口程订单，方案 B 是两张单程）
- [ ] 银行流水：近 3–6 个月，建议余额 **5 万以上**，稳定进账
- [ ] 在职证明（英文，含职位/薪资/准假时间）+ 营业执照复印件盖章
- [ ] **申根医疗保险**：医疗保额 ≥ €30,000，覆盖全程
- [ ] 户口本、身份证复印件
- [ ] 房产/车产（辅助资产，有就带）

**费用**：签证费约 €90（≈¥720）+ 签证中心服务费约 ¥200 左右

**怎么办**：VFS Global 代办奥地利签证，广州/深圳有中心，在官网预约系统约号。

## 二、钱和支付 ⚠️ 三个国家两种货币

| 国家 | 货币 | 欧元能用吗 |
|---|---|---|
| 奥地利 | **欧元 EUR** | ✅ |
| 捷克 | **克朗 CZK** | ⚠️ 部分收，但汇率极差 |
| 匈牙利 | **福林 HUF** | ⚠️ 同上 |

**准备**
- 主用**芯片信用卡**（Visa 或 Mastercard），带 **两张不同网络**的卡做备份
- 有 **Wise / Revolut** 多币种卡最好，实时汇率、免转换费
- 现金备 €150–200 等值（小店、公厕、市场、小费）
- 出发前**开通信用卡境外交易**，设好限额
- ⚠️ **刷卡被问"用人民币还是当地货币结算"→ 永远选当地货币**（人民币结算 = DCC，汇率能吃掉 5–8%）
- ⚠️ 银联在东欧覆盖一般，别只带银联

## 三、网络

- 中国运营商漫游贵 → 出发前买 **eSIM**（Airalo / 国内平台"欧洲多国流量包"）
- 或直接买一张欧洲多国 SIM 卡
- 奥地利、匈牙利属欧盟，同一张卡通用；捷克也在欧盟内
- ⚠️ 买之前确认手机**支持 eSIM** 且未锁网

## 五、城市交通 ⚠️ 三城都是"自觉打票 + 便衣查票"

| 城市 | 单程 | 通票 | 机场进城 |
|---|---|---|---|
| **维也纳** | €2.4 | 24h €8 / **72h €17.1** | ÖBB 城铁 **€4.2**（15–25 分钟）；CAT €13 不值 |
| **布拉格** | 30 CZK | 24h 120 CZK / 72h 330 CZK | 119 路公交 + 地铁，或 AE 机场快线 |
| **布达佩斯** | 450 HUF | **24h 2500 HUF / 72h 4150 HUF** | 100E 机场巴士 |

**通用规则**
- ⚠️ **没有闸机，必须自己打票 / 激活电子票**，查到逃票罚款重（维也纳约 €105）
- 电子票在官方 App 买最省事（WienMobil / PID Lítačka / BudapestGO）
- 有学生/青年票年龄限制，成人直接买通票最划算
- 打车票要在上车**前**打（打票机在车门旁 / 站台）

## 六、天气与穿着（1 月底是三国最冷的时候）

- 气温：布达佩斯 / 维也纳 / 布拉格 约 **-5 ~ 5°C**，湖区更低
- 可能下雪、路面结冰 → **防水防滑的鞋**是刚需
- 羽绒服 / 厚外套、手套、帽子、围巾、暖宝宝
- 室内暖气足 → **内穿薄、外穿厚**的洋葱式穿法
- ⚠️ 泡塞切尼温泉要带**拖鞋 + 泳衣 + 浴帽**（部分池要求）

## 七、时间 — 这是最容易被忽略的

- **时差**：中欧时间 UTC+1，比北京**晚 7 小时**
  - 去程 1/23 01:45 深圳起飞 → 当地 1/23 清晨抵达（等于没过夜，倒时差容易）
- ⚠️ **日照极短**：1 月底日出约 **07:20**，日落约 **16:45**
  - 实际能拍照游玩只有 **9 点到 16 点，约 7 小时**
  - **行程别排太满**，一天 3–4 个点是上限
  - 好处：夜景时间长（16:30 就天黑，多瑙河夜游船、国会大厦亮灯的时间很充裕）

## 八、安全

- **布达佩斯**：火车站、地铁 M2/M3、圣诞市场扒手多；警惕"假警察查钱包"和街边换汇骗局
- **布拉格**：街边 Exchange 汇率陷阱严重 → 只在银行取现或直接刷卡，**不在街头换钱**
- 护照复印件 + 云备份（护照、签证、保险、机票、酒店）
- 紧急电话：全欧统一 **112**
